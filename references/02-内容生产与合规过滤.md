# 02 内容生产与合规过滤

## 一、选题：需求驱动，不是资源驱动

**错误路径**：用户擅长什么 → 写什么。这是资源驱动，用户自己就能做，而且极容易撞红海。
**正确路径**：算出赛道里什么稀缺 → 决定写什么 → 再看手上有什么素材能支撑。

### 选题池优先级
1. 稀缺度报告里的**强稀缺词**（且供给数据完整）
2. 自有真实案例能串成的完整工作流（系列主线，可反复拆解）
3. 通用选题库（兜底）

### 每周配比（可按复盘结果调整）
| 支柱 | 占比 | 作用 |
|---|---|---|
| 真实工作流拆解 | 50% | 主力，建立专业感 |
| 场景提效 | 30% | 扩大搜索面 |
| 踩坑与限制 | 20% | 建立信任（讲"什么时候不该用"最容易被信） |

**每周硬性下限**：至少 1 篇踩坑限制类、1 篇可搜索清单类、1 篇完整流程拆解。

## 二、内容硬性结构

每条内容必须同时具备四项，**缺一不可**：
1. **可执行的判断规则或具体流程**（不是观点，是能抄走的步骤）
2. **真人判断**（哪一步是人做的决定）
3. **过程证据**（可核验的事实、截图、数据）
4. **适用边界**（什么时候这一步不该做）

### 成稿模板
```
[钩子]  用可核验的事实或一个反常识判断开场（不要用"随着AI的发展…"）
[转折]  说出真实的反应或认知变化
[方法]  分点给流程，每点一句结论 + 一句怎么做
[边界]  明确说明什么时候不该这么做
[收口]  一句立场（不是总结，是态度）
[互动]  一个具体的问题（不是"你怎么看"）
[来源]  涉及外部事实时必须标注
```

### 标题
一次给 3 个备选，分属不同类型（数字清单型 / 反常识型 / 场景痛点型），
禁止极限词，禁止无法核验的倍数与收益。

## 三、合规一票否决

命中以下任一条 → 直接淘汰或改写为合规角度，**不做"风险提示"就算完**：

| 类别 | 典型表达 |
|---|---|
| 效果承诺 | 彻底解决、100% 有效、保证通过 |
| 收益承诺 | 月入 X、躺赚、稳定回本 |
| 极限词 | 最强、第一、唯一、顶级、绝了（封面可保留但需谨慎） |
| 引流导流 | 加微信、私信领取、站外链接、二维码 |
| 伪造 | 编造体验、案例、数据、用户反馈 |
| 禁推品类 | 药品、医疗器械、医美、保健食品 |
| 无法核实 | 引用无来源的数据与趋势 |

### 平台/赛道专属红线（以 AI 赛道为例）
- 不出现"用 AI 月入 X""一键生成爆款""效率提升 X 倍"等无法核验的收益或效果承诺
- **不教**规避平台检测、"降 AI 率"、代写代改、批量注册、刷量、限制绕过
- 涉及 AIGC 检测的话题，**只讲规范使用、误判风险与自证方法**，绝不教规避
- 不展示登录态、Cookie、密钥、私密路径、平台后台界面
- 工具 Logo 与界面截图需有使用权；不碰破解版、共享账号
- AI 内容标注规则**以平台当前官方规则为准**，交付中提示人工确认

## 四、红黄绿灯输出

每篇交付必须给出判断：
- **绿灯**：可写
- **黄灯**：需改写后再写（写明改哪里）
- **红灯**：放弃该选题，并给出同需求的**合规替代角度**

红灯必须给替代角度——只否掉不给出路，等于没帮上忙。

## 五、敏感表达自查表（每篇必须附）

| 风险词 | 类别 | 安全替换 |
|---|---|---|
| 彻底解决 | 效果承诺 | 明显减少 / 大部分情况能避免 |
| 效率提升 10 倍 | 无法核验 | 这一步从几十分钟降到几分钟（示例值，需替换为真实） |
| 必看 / 最强 | 极限词 | 值得一看 / 比较省心 |
| 私信我领 | 引流 | 评论区说说你的情况 |

若本机配置了违禁词库 API，必须调用并把命中词与替换建议写入交付；
未配置时只做规则自查，**并明确提示"未做词库检测，需人工复核"**。
